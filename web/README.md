# ساعت‌باشی — نسخه وب

نسخه وب اپلیکیشن ساعت‌باشی: پیگیری نماز و روزه قضا، تقویم فارسی و اوقات شرعی، بدون نیاز به نصب.

ساخته‌شده با Vite + React + TypeScript. تمام داده‌ها (شمارنده‌های قضا) در `localStorage` مرورگر ذخیره می‌شوند و جایی ارسال نمی‌شوند.

## توسعه

```bash
npm install
npm run dev
```

## ساخت نسخه‌ی نهایی

```bash
npm run build
```

خروجی در پوشه‌ی `dist/` قرار می‌گیرد. هر صفحه‌ی عمومی موقع build به‌صورت HTML ثابت ساخته می‌شود (`scripts/prerender.mjs`) تا موتورهای جست‌وجو و پیش‌نمایش لینک‌ها محتوای کامل و عنوان و توضیح هر صفحه را بدون اجرای جاوااسکریپت ببینند؛ سپس React روی همان HTML hydrate می‌شود. بخش‌هایی که به زمان حال یا حافظه‌ی مرورگر وابسته‌اند (ساعت، تقویم امروز، اوقات شرعی، شمارنده‌های قضا) فقط در مرورگر ساخته می‌شوند تا HTML ثابت تاریخ کهنه نداشته باشد.

برای آدرس canonical و `sitemap.xml` نشانی عمومی سایت را بدهید:

```bash
SITE_URL=https://atid.example.com npm run build
```

بدون `SITE_URL` صفحه‌ها ساخته می‌شوند ولی canonical و sitemap حذف می‌شوند. در ورک‌فلوی Images این مقدار از متغیر مخزن `ATID_SITE_URL` (Settings → Secrets and variables → Actions → Variables) خوانده می‌شود.

مسیرها تمیزند (`/app/texts/ziyarat_ashura`) و لینک‌های قدیمی `/#/...` به نشانی جدید منتقل می‌شوند. اطلاعات SEO هر صفحه در `src/seo.ts` است.

## دیپلوی

نسخه وب با Docker و Caddy روی سرور اجرا می‌شود و بعد از موفق شدن CI روی `master` خودکار دیپلوی می‌شود. راهنمای کامل در [`deploy/README.md`](../deploy/README.md) است.

## ساختار

- `src/lib/persianDate.ts` — تبدیل تقویم میلادی↔جلالی (پورت‌شده از منطق اپ اندروید)
- `src/lib/prayerTimes.ts` — محاسبه‌ی اوقات شرعی (پورت‌شده از منطق اپ اندروید)
- `src/data/religiousTexts.ts` — متون مذهبی
- `src/store/qadaStore.ts` — مخزن شمارنده‌های قضا روی localStorage
- `src/pages/` — صفحات (لندینگ، قضا، تقویم، اوقات شرعی، متون مذهبی)
