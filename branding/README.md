# هویت ساعت‌باشی

تصویرسازی کامل `source/saatbashi-approved.png` مرجع شخصیت باقی می‌ماند. پنل راهنما به صورت تکراری در همه صفحه‌ها نمایش داده نمی‌شود.

آیکون‌ها نشان برداری ساده‌ای از همان شخصیت‌اند: سر طاس، فرهای سفید دو طرف، عینک گرد و لبخند. در اندازه کوچک از تصویر کامل یا برش تصویرسازی استفاده نکنید. وب و اندروید از هندسه مشترک `generate.py` ساخته می‌شوند؛ نسخه تک‌رنگ و تصویر اعلان‌های اندروید نیز همین هندسه را دنبال می‌کنند. تصویر اعلان در `drawable-nodpi/saatbashi_notification.png` با اندازه ۱۲۸ پیکسل ساخته می‌شود.

```bash
python3 branding/generate.py
npm i --no-save playwright
node branding/rasterize.mjs
```

برای ساخت فایل تصویرسازی کامل، `python3 branding/build_character.py` را با Pillow اجرا کنید؛ این دستور آیکون‌ها را تغییر نمی‌دهد. خروجی‌ها را دستی تغییر ندهید. شناسه بسته و استقرار همچنان `atid` است.
