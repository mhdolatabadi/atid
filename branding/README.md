# هویت ساعت‌باشی

شخصیت تأییدشده در `source/saatbashi-approved.png` مرجع اصلی است: پیرمرد مهربان و فانتزی با سر طاس، موهای سفید فرفری، عینک گرد، سبیل سفید، لباس سرمه‌ای و کرم و ساعت جیبی طلایی. از بازطراحی خودکار یا جایگزین کردن او با یک شخصیت متفاوت خودداری کنید.

نمای کامل در راهنماهای وب و اندروید و نمای نزدیک همان چهره در آیکون‌ها و تصویر اشتراک‌گذاری استفاده می‌شود. زمینه کرم تصویر اصلی عمداً حفظ شده تا جزئیات چهره تغییر نکند. تصویر هنوز یک اثر شطرنجی است؛ SVG وب آن را درون خود دارد.

لحن گرم، ساده و متناسب با هر بخش است. پیام‌ها کاربر را سرزنش نمی‌کنند، اطلاعات زمانی زنده جعل نمی‌کنند و متون مذهبی را تغییر نمی‌دهند. راهنما در جریان صفحه است و روی محتوا قرار نمی‌گیرد.

## ساخت مجدد

```bash
python3 branding/build_character.py  # نیازمند Pillow؛ خروجی وب و اندروید از تصویر تأییدشده
python3 branding/generate.py         # زمینه و نشان تک‌رنگ native برای themed icons
```

`rasterize.mjs` ابزار قدیمی رندر لوگوی برداری است و برای این هویت نباید اجرا شود. تغییر source باید با تأیید چهره جدید همراه باشد. شناسه‌های مخزن و بسته اندروید همچنان `atid` هستند.
